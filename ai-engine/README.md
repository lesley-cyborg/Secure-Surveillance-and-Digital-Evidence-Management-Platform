# Secure Surveillance AI Engine

Production-oriented computer-vision service for the Secure Surveillance Platform.

## Features

- FastAPI inference API
- Ultralytics YOLO object detection
- CPU and CUDA device selection
- Model checksum validation
- Model lifecycle management
- Inference concurrency limiting
- Liveness and readiness endpoints
- Docker CPU deployment

## Supported detections

- Person
- Bicycle
- Car
- Motorcycle
- Bus
- Truck
