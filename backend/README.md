# Secure Surveillance Platform Backend

Phase 3 foundation for the FastAPI, PostgreSQL, Redis, and object-storage implementation.

## Included

- FastAPI application factory and lifespan management
- Async SQLAlchemy 2.0 engine and session factory
- PostgreSQL ORM model graph derived from the ERD
- Alembic initial-schema and RBAC seed migrations
- Append-only database triggers for audit and custody records
- Redis readiness integration
- Correlation IDs, security headers, trusted hosts, and CORS
- Docker Compose services for PostgreSQL, Redis, MinIO, and the API
- Liveness and readiness endpoints
- First-administrator bootstrap script

## Windows PowerShell setup

```powershell
cd backend
Copy-Item .env.example .env
# Replace JWT_SECRET_KEY in .env with a random value of at least 32 characters.

python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"

docker compose up -d postgres redis minio
alembic upgrade head
uvicorn app.main:app --reload
```

Or run:

```powershell
.\scripts\bootstrap.ps1
```

## Create the first administrator

Run the migrations first, then:

```powershell
python -m scripts.create_admin `
  --email admin@example.com `
  --username administrator `
  --first-name System `
  --last-name Administrator
```

The password is requested securely and is not accepted as a command-line argument.

## Health endpoints

- `GET /api/v1/health/live` — process liveness
- `GET /api/v1/health/ready` — PostgreSQL and Redis readiness
- Development Swagger UI — `http://localhost:8000/docs`

## Migration workflow

```powershell
alembic upgrade head
alembic revision --autogenerate -m "describe change"
alembic check
alembic downgrade -1
```

Always review autogenerated migrations. Database triggers, PostgreSQL functions, partial indexes,
and forensic immutability rules require deliberate migration code.
